学习率怎么影响梯度下降的收敛

学习率太小，走得慢；太大，会来回震荡，甚至越走越远。拖动下面的滑块，亲眼看这三种情况。

损失函数 f(x) = x²。橙色折线是每一步的位置。
每一步的损失 f(x)，共 20 步。

文字解释

梯度下降是一种找最小值的方法。它每一步都做同一件事：沿着下坡方向走一步。

这个页面用最简单的损失函数 f(x) = x²。它的最小值在 x = 0。它在 x 处的坡度（梯度）是 2x。

每一步的更新规则是：

新的 x = x − η × 2x = (1 − 2η) × x

η 就是学习率：每一步沿坡度走多远。上面的式子说明，每走一步，x 都乘以同一个数 (1 − 2η)。所以结果只看这个数：

  • 0 < η < 0.5：这个数在 0 和 1 之间。x 每步变小，一直停在同一侧。η 越小，走得越慢。
  • η = 0.5：这个数等于 0。一步就到最低点。
  • 0.5 < η < 1：这个数在 −1 和 0 之间。x 每步跳到另一侧，但跳得越来越近，最后仍然收敛。
  • η = 1：这个数等于 −1。x 在两侧来回跳，永远不变近。
  • η > 1：这个数小于 −1。x 每步跳得更远，损失越来越大。这叫发散。

试试这样拖

  1. 把 η 拖到 0.05，数一数 20 步后离最低点还有多远。
  2. 把 η 拖到 0.8，看折线怎么在两侧来回跳，但越跳越近。
  3. 把 η 拖到 1.05，看损失曲线怎么往上翘。

需要核对

  • 这里只有一个参数 x，损失函数是最简单的抛物线。真实模型有上百万个参数，损失曲面更复杂。但「太大会震荡或发散，太小会很慢」这个规律仍然成立。
  • 对 f(x) = x²，收敛条件是 0 < η < 1。换一个损失函数，这个界限会变。一般规律是：曲面越陡，能用的学习率越小。
