# 操作步骤：配置 GitHub SSH 密钥

**请求**：把下面这段改写得好懂一点。

## 前

> 在正式开始使用之前，您首先需要确保本地已经生成了 SSH 密钥对，如果还没有的话可以通过执行 ssh-keygen -t ed25519 -C "你的邮箱" 来进行生成，过程中会提示输入保存路径和密码短语，一般直接回车使用默认值即可，然后需要将 ~/.ssh/id_ed25519.pub 中的内容复制下来并添加到 GitHub 的 Settings → SSH and GPG keys 页面中，完成之后可以通过 ssh -T git@github.com 来对连接进行验证，如果看到包含你用户名的欢迎信息就说明配置成功了，不过需要注意的是，如果公司网络屏蔽了 22 端口，那么这一步可能会超时，这种情况下可以考虑改用 443 端口。

## 后

> 如果本机已经有 SSH 密钥对，跳过第 1–2 步。
>
> 1. 在终端运行 `ssh-keygen -t ed25519 -C "你的邮箱"`，生成密钥对。
> 2. 程序提示输入保存路径和密码短语时，一般直接按回车，使用默认值。
> 3. 复制 `~/.ssh/id_ed25519.pub` 文件的全部内容。
> 4. 打开 GitHub 的 **Settings → SSH and GPG keys** 页面，添加刚才复制的内容。
> 5. 运行 `ssh -T git@github.com`，验证连接。
>
> 看到含有你用户名的欢迎信息，说明配置成功。
>
> 如果第 5 步超时：公司网络可能屏蔽了 22 端口。这时可以考虑改用 443 端口。
